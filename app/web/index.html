界面脚本未能加载

    
本页面使用 ES 模块（js/*.js）。浏览器出于同源策略会拦截通过
      file:// 直接打开的模块脚本，因此请通过 HTTP 访问：

    
    
      
  • 启动后端：由 FastAPI 把 app/web/ 挂载为静态站点，访问其地址；
    • 
      
  • 或本地临时预览：在本目录执行 python -m http.server 8000，
        然后打开 http://127.0.0.1:8000/index.html?demo=1。
    • 
    

    
若已通过 HTTP 打开仍看到本提示，请检查浏览器控制台的报错。
