一次覆盖整周免费/小型场次，是性价比最高的一类

2. 爬虫技术方案

2.1 路由优先级（按可靠性从高到低）

① SSR HTML 直取          → 最快最稳，秀动用这条
② XHR JSON 拦截          → 让页面自己请求，我们抄它的 JSON（微博/B站）
③ 渲染后 DOM 读取        → SPA 页面（小红书）
④ 截图 + 视觉分析        → 兜底（当前未启用）

核心原则：绝不逆向接口签名。 ② 的做法是「打开页面 → 拦截网络响应」， 不是伪造签名或注入 Cookie。项目全程不注入 Cookie、不伪造签名、 不改 navigator.webdriver 之类指纹。

2.2 各源实现要点

源关键实现
秀动城市页 + 场地页（场地页给更多阵容）；httpx 直取，无需浏览器
豆瓣官方 RSS；遵守 Crawl-delay: 5
B站CDP 打开会员购 → 点城市 → 拦截 /api/ticket/project；翻页用真实点击「下一页」
微博移动端（m.weibo.cn）搜索页 + 拦截 /api/container；containerid 必须整体 URL 编码

2.4 合规边界

  • 只用公开页面，不绕登录墙（小红书用维护者自己的登录态读公开笔记）
  • 不逆向签名、不伪造指纹、不注入 Cookie
  • 遵守 robots.txt 与 Crawl-delay
  • 标注来源并给免责声明（页面「数据来源与免责声明」弹窗）
  • 限速：单源串行，不并发轰炸

3.2 event / occurrence 分离

一次巡回演出 = 1 个 event + N 个 occurrence。这样：

  • 同一活动在广州/深圳两场不会变成两个「活动」
  • 系列键（series_key + series_vol）能把「PoP Star Vol.7/Vol.8」串起来

3.3 三层判重

  1. 源内：external_id 唯一约束
  2. 跨源：标题归一化 + 时间 + 场地相似度
  3. 人工：拿不准的进 review_task，绝不静默合并

当前待复核 52 条（conflict 47 / 按阵容重分类 5）。

3.4 时间与时区

  • SQLite 存朴素时间，API 输出时统一补 +08:00（aware()）
  • 日期精度分 datetime / date_only / tbd
  • 过期判定按天（不是按时刻）—— 否则 date_only 的活动在当天下午就消失了

3.5 海报为什么走后端代理

豆瓣图片必须带 Referer 才返回（否则 418），B站封面是协议相对 URL。 所以后端代理 + 磁盘缓存（data/posters/，sha256 命名）。

秀动没有海报：列表页懒加载、详情页是 SPA 空壳（约 19KB，无 og:image）、 XHR 接口被拒（get_not_support／参数不全）。

is_acgACG / 二次元 / 同人 / 宅向

  • 静态站垂类过滤：= OR（任一为真即属垂类）

6.2 ⚠️ 采集后必须按顺序做后处理

顺序很容易搞错 —— 实测踩过：先 reclassify（按阵容）再 backfill（按标题） 会把阵容得到的结论清掉，事件就从日历里消失（koyo生诞祭应援 就是这样掉出去又恢复的）。

python -m app.cli refresh                # 采集 → artist-kb → reclassify → backfill → build-static
python -m app.cli refresh --no-fetch     # 只做后处理 + 重建
步骤为什么在这个位置
artist-kb必须最先 —— reclassify 要先把知识库同步进 artist 表
reclassify按阵容（最可靠），应在 backfill 之前
backfill只按标题；已改成与现有标记取并集（不再清掉上下文结论）
build-static必须最后 —— 否则导出旧标记

6.3 全部 CLI 命令

python -m app.cli initdb            # 建表
python -m app.cli migrate           # 结构迁移（给已有表补列）
python -m app.cli fetch             # 跑采集
python -m app.cli refresh           # 采集 + 后处理 + 重建（推荐）
python -m app.cli backfill          # 按标题回填标记（并集语义）
python -m app.cli reclassify        # 按阵容重分类
python -m app.cli artist-kb         # 同步演员知识库

python -m app.cli stats             # 看统计
